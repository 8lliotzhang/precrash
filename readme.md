# pre/crash
*dynamic risk determination for autonomous vehicles*

### Why?
Following ProjectX's 2026 theme of "What is Progress?", we chose to explore an aspect of self-driving vehicles which remains problematic to this day: accidents, or rather, how to avoid them. We intend to build a model which can generate a "risk value" based on dynamic conditions, including time of day, weather, vehicle model, and road configuration. This "risk value" can then be used to adjust vehicle behavior to minimize risks of injuries accordingly.
